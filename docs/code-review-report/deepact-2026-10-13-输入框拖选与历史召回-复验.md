## 3. 修复质量评价

1. **修的是根因而不是症状**：没有在 `inputRowRuneAt` 里局部补一个 `+换行数`，而是让 `wrapInputRows` 成为行起点的唯一来源，渲染与命中测试共用同一份偏移——正是上轮建议的"从根上消除两份行偏移逻辑"。`wrapInputRows` 的注释把"`\n` 是文本的 rune 但不是行的 rune"这一根因写清楚了。
2. **顺带补齐了防御分支**：`inputRowRuneAt` 新增 `idx >= len(rows)` 时 clamp 到输入末尾（`ui/input_selection.go:101-105`），使"拖到输入框下方"的行为确定而非隐式。
3. **每个修复都配了会在旧实现下失败的回归测试**（尤其 popup 带与多行两例），而不是事后补一个"存在即通过"的断言。
4. **注释与行为同步**：popup 守卫的注释随行为改写；PasteMode 的取舍以注释+测试固定，不再是未定义行为。
